# ACE-Step 1.5 で曲を作る（Google Colab・無料の T4 GPU）

[![Open in Colab](https://colab.research.google.com/assets/colab-badge.svg)](https://colab.research.google.com/github/yoru-hitori-uta/ace-step-colab/blob/main/ace_step_colab.ipynb)

YouTube チャンネル「夜、ひとりで聴く歌」用。Google ドライブに置いた歌詞から、オープンソースの音楽生成 AI
[ACE-Step 1.5](https://github.com/ace-step/ACE-Step-1.5) で、1曲につき3パターンの曲を作ります。
PC に GPU がなくても、Google Colab の無料 GPU（T4）で動きます。

## 初回の手順

1. 上の **「Open in Colab」** を押す（Google アカウントでログイン）
2. メニュー **「ランタイム」→「ランタイムのタイプを変更」** を開き、「ハードウェア アクセラレータ」で **「T4 GPU」** を選んで **「保存」**
3. メニュー **「ランタイム」→「すべてのセルを実行」**
   - 「このノートブックは Google が作成したものではありません」と出たら **「このまま実行」**
   - 「Google ドライブへのアクセスを許可」の画面で、自分のアカウントを選び **「許可」**（チェックはすべて入れたまま）
4. 初回は、ドライブに `ace-step/lyrics/` と `ace-step/output/` ができ、動作確認用の歌詞「午前二時の既読」が入ります。
   10〜20分ほどで `ace-step/output/午前二時の既読/` に3パターンができ、いちばん下のセルで聴けます

2回目からは「Open in Colab」→「すべてのセルを実行」だけです（T4 の設定は保存されています）。

## 歌詞ファイルの書き方

ドライブの `ace-step/lyrics/` に、1曲1ファイル（`.txt`、UTF-8）で置きます。先頭の `---` より上が設定で、どれも省略できます。

```
タイトル: 午前二時の既読
スタイル: 切ないバラード, 女性ボーカル, ピアノ, ストリングス, 夜
BPM: 70
長さ: 100        # 秒（10〜600）。省略すると歌詞の長さから自動
キー: Am         # 省略すると自動
言語: ja         # 歌の言語。英語の曲は en
シード: 1, 2, 3  # パターンごとのシード。省略するとランダム（使った値は記録されます）
---
[Verse]
午前二時の 部屋の灯り
…
[Chorus]
…
```

- 「スタイル」は日本語でも英語でも書けます（ジャンル・雰囲気・声・楽器・テンポなど）
- 歌詞の `[Verse]` `[Chorus]` などのタグは、そのまま曲の構成として使われます

## できるもの

```
ace-step/output/午前二時の既読/
  take1.flac  take1.json   ← 1パターン目の音声と、使ったシード・設定
  take2.flac  take2.json
  take3.flac  take3.json
  lyrics.txt               ← 歌詞（設定を除いたもの。取り込みに使う）
  song.json                ← 曲の設定
```

- 途中で止まっても、もう一度「すべてのセルを実行」すれば、できていないパターンだけ作ります
- 作り直したいパターンは、その `takeN.flac` と `takeN.json` を消してから実行します

## 設定（ノートブックの①）

| 項目 | おすすめ | 説明 |
|---|---|---|
| 音楽を作るモデル | 2B turbo | 速い（8ステップ）。「2B sft」は高品質だが遅い。「XL」は T4 ではメモリ不足で動かない可能性が高い |
| 作曲用の言語モデル | 0.6B | BPM・キー・構成を考える。T4 では 0.6B が安全 |
| パターン数 | 3 | |
| 形式 | flac | wav の約半分の大きさで、音質は同じ |

## 無料の Colab での注意

- 使える時間に上限があります（目安: 1日数時間。続けて使うと GPU が割り当てられないことがあります）
- 何もしないと 90 分ほどで切断されます。切断されたら、もう一度「すべてのセルを実行」すれば続きから作ります
- 準備（ACE-Step のインストールとモデルのダウンロード）は、毎回 5〜10 分かかります

## PC のツール（shorts-tool）に取り込む

PC に [Google ドライブ for デスクトップ](https://www.google.com/drive/download/) を入れ、同じ Google アカウントでログインすると、
エクスプローラーに「Google Drive（G:）→ マイドライブ → ace-step」が出ます。

```
uv run python -m shorts_tool ace-import                       # 作った曲とパターンの一覧
uv run python -m shorts_tool ace-import 午前二時の既読 --take 2  # 2パターン目を取り込む（incoming へ）
```

取り込んだ曲は、これまでと同じく自動化（ショート3本 → フル版）に流れます。
